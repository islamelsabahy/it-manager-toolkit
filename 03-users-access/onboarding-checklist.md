# IT Employee Onboarding Checklist

## Before Start Date
- [ ] Approved employee request received
- [ ] Job title / department confirmed
- [ ] Start date confirmed
- [ ] Manager confirmed
- [ ] Required applications identified
- [ ] Required permissions approved
- [ ] Device assigned / prepared
- [ ] Email account created
- [ ] ERP / CRM account prepared
- [ ] MFA configured where applicable
- [ ] Phone / extension prepared if required
- [ ] Access card / attendance prepared if in IT scope

## Device
- [ ] OS patched
- [ ] Endpoint security
- [ ] Encryption
- [ ] Productivity suite
- [ ] Browser
- [ ] VPN if required
- [ ] Company policies
- [ ] Asset handover completed

## First Day
- [ ] Login tested
- [ ] Email tested
- [ ] Required apps tested
- [ ] Shared folders / collaboration tested
- [ ] Security awareness provided
- [ ] Support channel explained
