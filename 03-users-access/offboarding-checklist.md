# IT Employee Offboarding Checklist

## Trigger
- [ ] Approved HR/management offboarding notification received
- [ ] Last working date confirmed
- [ ] Manager confirmed

## Access
- [ ] Disable identity/email according to approved timing
- [ ] Revoke VPN
- [ ] Revoke ERP/CRM
- [ ] Revoke privileged accounts
- [ ] Remove shared mailbox / group access
- [ ] Revoke SaaS applications
- [ ] Reset shared credentials if required

## Assets
- [ ] Laptop returned
- [ ] Mobile returned
- [ ] Accessories returned
- [ ] Access cards / tokens returned
- [ ] Asset condition checked
- [ ] Asset register updated

## Data
- [ ] Business data ownership transferred
- [ ] Required mailbox/files retained according to policy
- [ ] Backup/retention requirements completed

## Closure
- [ ] Licenses reclaimed
- [ ] Forwarding/delegation approved if used
- [ ] Checklist signed off
