# Access Control Matrix

| Role | System | Access Level | Business Owner | IT Owner | Approval Required | Review Frequency |
|---|---|---|---|---|---|---|
| Finance User | ERP | Finance User | CFO | IT | Yes | Quarterly |
| IT Admin | Infrastructure | Privileged | IT Manager | IT | Yes | Quarterly |

## Access Principles
- Least privilege
- Role-based access
- Named accounts
- MFA for privileged / high-risk systems where supported
- Periodic review
- Immediate leaver revocation
- Separation of duties where required
