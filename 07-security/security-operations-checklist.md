# Security Operations Checklist

## Identity
- [ ] MFA enabled where appropriate
- [ ] Privileged accounts separated
- [ ] Dormant accounts reviewed
- [ ] Leavers removed
- [ ] Shared accounts minimized
- [ ] Access reviews scheduled

## Endpoints
- [ ] Endpoint protection active
- [ ] OS patches current
- [ ] Disk encryption applied where required
- [ ] Local admin controlled
- [ ] Unsupported OS identified

## Network
- [ ] Firewall rules reviewed
- [ ] Guest network isolated
- [ ] Management interfaces restricted
- [ ] Unused services disabled
- [ ] Network device backups available

## Email
- [ ] SPF configured
- [ ] DKIM configured where supported
- [ ] DMARC configured/reviewed
- [ ] Anti-phishing protections enabled
- [ ] Suspicious forwarding reviewed

## Data
- [ ] Critical data identified
- [ ] Backup coverage confirmed
- [ ] Restore testing completed
- [ ] Sensitive data access reviewed

## Monitoring
- [ ] Security incidents tracked
- [ ] Critical alerts have owners
- [ ] Logs retained according to need
- [ ] Recurring security review performed
