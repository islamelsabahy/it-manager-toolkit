# Branch / Office IT Readiness Checklist

## Connectivity
- [ ] Primary internet installed
- [ ] Backup link considered/installed
- [ ] ISP handoff tested
- [ ] Static IP requirement confirmed

## Network
- [ ] Rack installed
- [ ] UPS installed
- [ ] Router/firewall configured
- [ ] Switches configured
- [ ] AP coverage tested
- [ ] VLANs configured
- [ ] Guest Wi-Fi isolated
- [ ] Patch panel / cabling labeled

## Users
- [ ] Workstations ready
- [ ] Printers ready
- [ ] Email/accounts ready
- [ ] ERP/CRM access tested

## Physical Systems
- [ ] CCTV operational
- [ ] Recording verified
- [ ] PBX/phones tested
- [ ] Attendance system tested
- [ ] Access control tested if applicable

## Security / Documentation
- [ ] Admin credentials stored securely
- [ ] Network diagram updated
- [ ] IP plan updated
- [ ] Asset register updated
- [ ] Backup/monitoring enabled
- [ ] Handover completed
