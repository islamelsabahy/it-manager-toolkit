# Asset Lifecycle Checklist

## Request
- [ ] Business need documented
- [ ] User / department identified
- [ ] Budget available
- [ ] Approval received

## Procurement
- [ ] Specification approved
- [ ] Quotations evaluated
- [ ] PO / purchase approval completed
- [ ] Warranty terms confirmed

## Receive
- [ ] Device physically inspected
- [ ] Serial number captured
- [ ] Asset ID assigned
- [ ] Warranty end recorded

## Configure
- [ ] OS updated
- [ ] Endpoint security installed
- [ ] Encryption enabled if required
- [ ] Required applications installed
- [ ] User access configured
- [ ] Backup/sync policy applied

## Assign
- [ ] Handover form signed
- [ ] User assigned in asset register
- [ ] Location recorded

## Maintain
- [ ] Warranty tracked
- [ ] Incidents linked to asset
- [ ] Repairs documented
- [ ] Health/status reviewed

## Retire
- [ ] Business approval
- [ ] Data backed up if required
- [ ] Secure wipe completed
- [ ] Accounts/licenses removed
- [ ] Disposal method recorded
