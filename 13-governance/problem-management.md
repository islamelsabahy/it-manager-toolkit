# Problem Management

## Purpose
Reduce recurring incidents by identifying root causes and implementing permanent corrective actions.

## Root Cause Techniques
- 5 Whys
- Fishbone / Ishikawa
- Timeline analysis
- Change correlation
- Vendor escalation
- Log/event correlation

## Closure Criteria
- Root cause documented or risk explicitly accepted
- Workaround documented if applicable
- Corrective action implemented or approved
- Related incidents reviewed
- Knowledge base updated
