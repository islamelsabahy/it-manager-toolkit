# SOP — Backup Monitoring

## Daily / Scheduled Review
1. Review backup job status.
2. Investigate failed jobs.
3. Re-run or correct failures according to platform.
4. Escalate if recovery objectives are at risk.
5. Record recurring failures.

## Periodic Restore Test
1. Select representative backup.
2. Restore into approved test location.
3. Validate readability/integrity.
4. Record recovery time.
5. Record test result.
6. Correct gaps.

## Principle
A successful backup job is not proof of recoverability; restore testing is required.
