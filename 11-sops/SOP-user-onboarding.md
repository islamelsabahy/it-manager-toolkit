# SOP — IT User Onboarding

## Purpose
Ensure new employees receive approved IT access and assets securely and on time.

## Trigger
Approved HR/management onboarding request.

## Owner
IT.

## Procedure
1. Validate employee, department, manager, start date, and location.
2. Confirm approved access requirements.
3. Prepare device according to standard build.
4. Create required accounts.
5. Apply security controls.
6. Test login and applications.
7. Complete asset handover.
8. Record assets and access.
9. Provide support/security orientation.
10. Close onboarding request with evidence.

## Control
No access should be granted solely through informal verbal request when formal approval is required.
