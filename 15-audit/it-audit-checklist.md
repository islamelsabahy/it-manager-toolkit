# IT Audit Checklist

## Governance
- [ ] IT responsibilities documented
- [ ] Policies/SOPs current
- [ ] Major risks tracked
- [ ] Projects and priorities approved
- [ ] Vendor ownership clear

## Assets
- [ ] Asset register maintained
- [ ] Asset assignments traceable
- [ ] Warranty status tracked
- [ ] Retired assets controlled
- [ ] Secure disposal evidenced

## Identity & Access
- [ ] Joiner/Mover/Leaver process exists
- [ ] Privileged access reviewed
- [ ] Dormant accounts reviewed
- [ ] MFA used where appropriate
- [ ] Shared accounts controlled

## Infrastructure
- [ ] Network inventory current
- [ ] Critical configurations backed up
- [ ] Unsupported devices identified
- [ ] Monitoring exists for critical services
- [ ] Capacity constraints tracked

## Security
- [ ] Endpoint protection coverage reviewed
- [ ] Patch compliance measured
- [ ] Security incidents recorded
- [ ] Email security controls reviewed
- [ ] Vulnerability/remediation activities tracked where applicable

## Backup & Recovery
- [ ] Backup inventory exists
- [ ] Failures monitored
- [ ] Retention documented
- [ ] Restore testing evidenced
- [ ] DR plan current

## Vendors & Licensing
- [ ] Contracts/renewals tracked
- [ ] Critical vendor SLAs measured
- [ ] License inventory maintained
- [ ] Unused subscriptions reviewed

## Service Management
- [ ] Helpdesk tickets tracked
- [ ] SLA measured
- [ ] Major incidents documented
- [ ] Recurring problems reviewed
- [ ] Production changes controlled

## Reporting
- [ ] IT KPIs reported
- [ ] Budget tracked
- [ ] Major risks escalated
- [ ] Management actions recorded

## Audit Output
For every gap record: finding, evidence, risk, owner, corrective action, target date, and status.
