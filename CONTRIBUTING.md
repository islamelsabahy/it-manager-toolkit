# Contributing

Contributions are welcome.

## Good Contributions
- Better IT operations templates
- Security control checklists
- Vendor-management methods
- Helpdesk metrics
- Infrastructure documentation patterns
- Automation examples
- Dummy-data examples

## Rules
1. Do not include confidential customer or employer data.
2. Use dummy names, IPs, costs, credentials, and asset identifiers.
3. Avoid publishing secrets, passwords, tokens, private keys, or sensitive network diagrams.
4. State assumptions.
5. Keep templates practical and auditable.
